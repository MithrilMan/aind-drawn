The systemArchitecture before spectacle

An asset is not a sprite.
It is a durable identity with ways to appear.

Semantic families own their vocabulary. Representation adapters own how that vocabulary is drawn. Generic runtimes own rendering and lifecycle. Nobody teaches the core what a wheel is just because a car exists.

Read the architecture ↗
  1. 01 / Identity

    Generate meaning once.

    Archetype, proportions, palette roles, parts, topology, sockets, and interaction intent are resolved from namespaced deterministic streams.

  2. 02 / Blueprint

    Preserve spatial truth.

    Representation-neutral manifests keep semantic parts, colliders, pivots, and attachments aligned across adapters.

  3. 03 / Projection

    Change the medium, not the subject.

    Raster, smooth-solid, and inked-solid projections consume the same identity without rerolling its recognisable traits.

  4. 04 / Runtime

    Let the asset participate.

    Motion, expressions, articulated state, collisions, interactions, and scene composition target semantic parts instead of pixels.

The identity is the hand-off.

Create it once, then choose how the same resolved subject enters the world.

// One semantic source, two projections.
const identity = createCharacterIdentity(4107, {
  species: 'human',
});

const drawing = new SpriteRig(
  createRasterCharacterBlueprint(identity, {
    medium: 'graphite',
  }),
);

const solid = new SolidRig(
  createSolidCharacterBlueprint(identity, {
    finish: 'ceramic',
  }),
);
